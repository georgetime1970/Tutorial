# Secrets of Power Negotiating

绝对成交 罗杰·道森（Roger Dawson）

## 第1部分 谈判的重要性（奠定心智与双赢基调）

- **第1章 21世纪的销售：** 现代销售环境已发生剧变，客户的信息渠道更广、选择更多。单纯的推销已经失效，未来的顶级销售员必须同时是高超的谈判专家，通过利益博弈赢得订单并维持利润。
- **第2章 “双赢”的谈判：** 双赢不是指各让一步、平分利益，而是在为自己争取最大利益的同时，通过高超的心理策略，让对方在谈判结束时也觉得自己赢了。如果让对方觉得自己输了，他们就会想办法在后续执行中报复。
- **第3章 谈判其实有章可循：** 谈判不是随机的口舌之争，而是一门有特定规律、步骤和技巧的科学。只要掌握了其固定的开局、中场、终局模型，任何人都可以在谈判桌上掌控主动。

## 第2部分 开局策略（建立优势与试探底线）

- **第4章 敢于开价：** 开出高于你预期的条件（MPT - Maximum Plausible Position）。留出让步的博弈空间，并可能拔高产品在对方心中的价值，试探买家底线。
- **第5章 框定范围：** 利用对方报价，在谈判初始划定一个利益区间。基于折中心理，`报价=底价*2-对方报价`。作为买方尽可能不要先开价。
- **第6章 绝不接受第一次报价：** 无论对方的第一次开价多么诱人，也绝对不要立刻答应。否则会让对方产生“我是不是吃亏了”或“我的开价太低了”的挫败感。

  | 反制技巧   | 核心话术                 | 适用场景                                                       |
  | ---------- | ------------------------ | -------------------------------------------------------------- |
  | 逼对方报价 | “那你的心理价位是多少？” | 对方刚生硬地拒绝你的第一次报价，需要打破僵局并摸清对方底线时。 |

- **第7章 学会表现惊讶（Flinch）：** 听到对方报价时，必须在肢体和言语上表现出极度吃惊。这能瞬间打击对方的自信心，暗示对方“你的要求太离谱了”。

  | 反制技巧 | 核心话术                                     | 适用场景                                             |
  | -------- | -------------------------------------------- | ---------------------------------------------------- |
  | 坚定沉默 | (保持微笑，直视对方，不发一言)               | 对方刚开始夸张表演的头5秒，用于击碎对方的心理战术。  |
  | 反问探底 | “您觉得是哪个具体的条款超出了您的预期？”     | 逼迫对方停止演戏，把话题拉回理性的商务讨论中。       |
  | 价值重塑 | “价格确实高，但这是因为我们包含了……”         | 对方开始攻击价格时，用高价值、高标准的服务硬顶回去。 |
  | 共情化解 | (FFF) “我理解您的感觉，但其他客户最后发现……” | 想要缓和谈判气氛，同时不想在核心利益上做出半步退让。 |

- **第8章 扮演不情愿的卖家：** 表现出“我其实不太想卖/非要达成这笔交易”的态度。这种心理暗示会逼迫对方主动降低预期，甚至为了促成交易而主动让步。

  | 反制技巧            | 核心话术                                       | 适用场景                                               |
  | ------------------- | ---------------------------------------------- | ------------------------------------------------------ |
  | 锁定唯一卡点        | “如果我们解决了这个问题，今天能直接签约吗？”   | 对方一直说“没兴趣/不想做”，需要确认其真实意图时。      |
  | 筹码对等交换        | “如果您能提高首付/增加订单量，我才好去申请。”  | 愿意做出让步，但必须咬下对方一块肉来作为补偿。         |
  | 撤回优惠 (以退为进) | “既然您这么勉强，那之前的免费福利就先取消吧。” | 对方演得太过了，需要给对方施加“即将失去利益”的危机感。 |

- **第9章 着眼谈判本身：** 不要把注意力集中在个人的情绪或面子上，而要聚焦于谈判桌上的筹码、规则和筹码交换本身。
- **第10章 老虎钳策略（The Vice）：** 无论对方开出什么条件，只说一句话：“你得再加/低点”，然后保持沉默，逼对方自己切掉利润。

  | 应对策略          | 核心话术                               | 适用场景                                           |
  | ----------------- | -------------------------------------- | -------------------------------------------------- |
  | 反向老虎钳 (首选) | “那您具体希望我调整多少呢？”           | 对方刚抛出老虎钳，需要立即打破沉默、逼对方报数时。 |
  | 对等交换          | “如果您能[交换条件]，我倒可以考虑。”   | 愿意做出一定让步，但必须咬下对方一块肉来作为补偿。 |
  | 探底澄清          | “如果价格再降一点，今天能直接签约吗？” | 确认这是不是对方唯一的卡点，防止陷入连环套。       |

## 第3部分 中场销售谈判策略（博弈中化解僵局与掌控主动）

- **第11章 更高权威法：** 永远不要让对方觉得你拥有最终决定权。假称需要“公司管委会”、“财务总监”或“老板”审批，用这个无形的盾牌来拒绝对方的要求，同时不伤和气。

  | 反制阶段     | 核心技巧 | 核心话术                                       | 适用场景                                           |
  | ------------ | -------- | ---------------------------------------------- | -------------------------------------------------- |
  | 开局（预防） | 权限测试 | “如果今天聊得合适，您这边能直接拍板对吧？”     | 谈判一开始，在双方建立信任和确认身份的阶段使用。   |
  | 中场（被动） | 条件锁定 | “如果我申请到了，你能保证这是最终合同吗？”     | 对方已经开始用“老板不批”作为砍价借口时。           |
  | 中场（反击） | 越级对话 | “要不我下周一直接去向你们老板做个面对面汇报？” | 对方级别较低，一直用高层当挡箭牌，导致谈判僵持时。 |
  | 全程（防御） | 镜像对轰 | “我们王总也卡得非常死，说这已经是亏本底线了。” | 对方用高层施压，我方需要对等顶回去时。             |

- **第12章 避免对抗性谈判：** 永远不要和客户产生正面冲突或辩论。使用“感到、觉得、发现”（Feel, Felt, Found）的沟通技巧，先站在对方立场，再委婉引出自己的优势。
- **第13章 持续衰减的服务价值：** 服务的价值在做完之后会迅速贬值。因此，所有的服务和赠品，必须在谈判过程中作为筹码抛出，绝对不要在成交后再免费赠送。
- **第14章 永远不要主动提议分摊差额：** 当双方僵持在某个价格差时，永远不要先说“那我们一人让一半吧”。这暴露了你的底线，正确的做法是引导对方先提出分摊，或者让对方提出。
- **第15章 烫手山芋：** 当对方把一个巨大的难题（如“我们真的没有预算了”）抛给你时，不要接。要通过提问把这个问题重新丢回给对方：“如果预算不够，我们要削减哪些配置？”
- **第16章 一定要索取回报（Tied Concession）：** 每次向对方做出让步时，必须同时索取回报。经典话术：“如果我们为您做到这点，您能为我们做些什么？”防止对方得寸进尺。

## 第4部分 终局销售谈判策略（锁定成交与营造“双赢”心理）

- **第17章 好人/坏人策略：** 经典双人配合。一人扮演严厉、寸步不让的坏人，另一人扮演富有同情心、看似在帮对方的好人，利用心理落差迫使对手向“好人”妥协。
- **第18章 蚕食策略（Nibbling）：** 在谈判几乎全部达成、双方心理最放松的最后关头，顺带提出一个微小但有利的要求（如：免费延保、包运费等），此时对方通常很难拒绝。
- **第19章 让步模式：** 让步的幅度必须呈现“逐步递减”的规律（如：先让1000，再让500，再让100，最后坚决不让）。如果让步幅度忽大忽小，会引发对方继续压价的贪婪。
- **第20章 收回报价：** 当谈判陷入僵局、对方贪得无厌时，可以果断声明“由于时间/成本变化，我必须收回之前的优惠报价”。通过制造失去的危机感，反向逼迫对方妥协。
- **第21章 “留面子”策略：** 在赢走利益的同时，必须在言语和形式上给对手留足面子。不要表现出沾沾自喜，要让对方觉得他们也是这场谈判的英雄。
- **第22章 起草合同：** 尽量由你方来起草合同初稿。因为起草合同的人拥有绝对的隐形主动权，可以在条款细节、免责、时效上做出有利于己方的设定。

## 第5部分 价格没有你想象的那么重要（突破价格死结）

- **第23章 客户其实愿意多花钱：** 只要你能证明产品能够帮他们省心、降低风险、提升身份或带来更高回报，客户其实并不介意支付溢价。
- **第24章 比价格更重要的东西：** 质量、交付速度、售后保障、品牌信誉、长期的心理安全感，这些要素在商业决策中往往排在单一价格的前面。
- **第25章 确定客户愿意付多少钱：** 不要盲目降价。通过层层递进的提问、测试性提议（“如果我们能把付款周期缩短，您在价格上能接受多少？”）来精准摸清对方的心理真实价位。

## 第6部分 优势成交的秘诀（促成签字的临门一脚）

- **第26章 销售的四个阶段：** 建立信任（建立联系）、挖掘需求（发现痛点）、展示方案（对症下药）、赢得承诺（谈判与最终成交）。
- **第27章 25种绝对成交策略：** 总结了25个具体的心理学与行为催化技巧（如：假设成交法、对比成交法、稀缺成交法等），在不同情境下快速逼单。
- **第28章 “陷阱”成交法：** 通过设定一个诱饵条件，让对方落入“如果我解决了这个问题，你就必须签字”的逻辑闭环中，堵死对方的推脱借口。

## 第7部分 如何掌控谈判（掌控全场与危机处理）

- **第29章 谈判动机：** 深入洞察对手在谈判桌背后的真正动机。有人要的是低价，有人要的是安全，有人只是要在老板面前表现出自己的谈判能力。
- **第30章 谈判中的那些“套路”：** 识别并防御对手常用的各种诡计，如：制造虚假时间限制、故意拖延、虚张声势等。
- **第31章 如何与非美国人谈判：** 探讨跨文化谈判。不同国家（如亚洲的含蓄慢节奏、欧洲的严谨、中东的漫天要价）有着截然不同的谈判习俗，必须因地制宜。
- **第32章 谈判压力点：** 学会利用“时间限制”（Time Deadline）、“竞争对手的存在”（Competition）等压力点去施压对方，打破僵局。
- **第33章 谈判中的问题：** 掌握“提问”的艺术。通过开放式问题套取情报，通过封闭式问题锁定承诺，少说多听。
- **第34章 如何应对愤怒的客户：** 面对愤怒，先处理情绪再处理事情。让对方宣泄，倾听、道歉（对感受表示遗憾而非直接认错），然后引导进入理性协商。

## 第8部分 理解你的对手（心理学与终极双赢）

- **第35章 增强个人影响力：** 提升谈判者的个人魅力与气场。包括专业度的展现、合法权力的运用、信息优势的掌握以及言出必行的信誉。
- **第36章 读懂客户的性格特点：** 将对手分为四种主要性格（实用型、分析型、表现型、和蔼型），针对不同性格采用完全不同的出牌和沟通方式。
- **第37章 双赢销售谈判：** 优势谈判的最高境界。双赢不是各让50%，而是“在拿走你想要的利益的同时，通过心理策略让对方带着胜利者的满足感离开谈判桌”。
