# 高级 Trait

## 关联类型

关联类型是 `Trait` 定义里的“占位符”，目的是为了让代码在 **“保证唯一性”** 的前提下，写起来更清爽。

### 挖坑与填坑

- 在 `Trait` 里“挖坑”：定义 `Trait` 时，我不确定具体的类型，先给它起个名字（比如 `type Item;`）。
- 在 `Impl` 里“填坑”：当你给某个具体的结构体实现这个 `Trait` 时，你必须指明这个坑里填什么（比如 `type Item = u32;`）。

### 使用语法

**普通用法**

```rust{3,11}
// 定义一个带关联类型的 Trait
trait MyTrait {
  type Value;
  fn get_value(&self) -> Self::Value;
}

struct MyStruct;

// 实现 Trait，指定关联类型为 i32
impl MyTrait for MyStruct {
  type Value = i32;
  fn get_value(&self) -> i32 {
    42
  }
}

fn main() {
  let s = MyStruct;
  println!("{}", s.get_value()); // 输出 42
}
```

**关联类型的约束 (Trait Bounds on Associated Types)**

```rust{5}
use std::fmt::Display;

trait Container {
    // 约束：不管你填什么类型，它必须实现了 Display（能打印）
    type Item: Display;

    fn print_item(&self, item: Self::Item) {
        // 因为有上面的约束，这里才敢直接用 println!
        println!("Value is: {}", item);
    }
}

```

**多个约束与 where 子句**

简单版:

```rust{2}
trait ComplexTrait {
    type Item: Display + Clone;
}
```

复杂版（把约束放在 where 子句里）:

```rust{5}
trait ComplexTrait {
    type Item;

    // 也可以在 Trait 定义的最下面统一写约束
    where Self::Item: Display + Clone;
}
```

### 关联类型 vs 泛型的

| 维度   | 泛型 `Trait` (`Trait<T>`)                                       | 关联类型 `Trait` (type Item)                       |
| ------ | --------------------------------------------------------------- | -------------------------------------------------- |
| 关系   | 多对多：一个结构体可以实现多次（比如 `Add<i32>` 和 `Add<f64>`） | 一对一：一个结构体只能实现一次，类型是锁死的       |
| 可读性 | 啰嗦：每次用这个 `Trait` 都要带上 `<T>`                         | 简洁：直接写 `Trait` 名，编译器自己去查那个 `type` |
| 语义   | 表示“多种可能”                                                  | 表示“这就是我的配套类型”                           |

### 何时使用

如果你在写一个 `Trait`，问自己一个问题：

“对于同一个泛型结构体，需不需要为不同类型实现同一个 `Trait`？”

- 不需要（选关联类型）：比如迭代器 `Iterator`。一个 `Vec<u32>` 的迭代器，吐出来的一定是 `u32`，不可能又是 `u32` 又是 `String`。这时候用关联类型，用户调用 `.next()` 时就不需要手动标注类型，非常省心。
- 需要（选泛型）：比如加法 `Add`。一个数字可能要加整数，也可能要加浮点数。这时候用泛型，允许你为同一个结构体写多个 `impl`。

## 默认泛型类型参数

**默认泛型类型参数（Default Generic Type Parameters）** 允许你为泛型指定一个默认的类型。如果在使用时没有显式指定具体类型，Rust 就会使用这个默认值。

### 定义语法

语法: `<PlaceholderType=ConcreteType>`

```rust{1}
trait Add<Rhs=Self> {
    type Output;

    fn add(self, rhs: Rhs) -> Self::Output;
}
```

> 如果你不指定 `Rhs`，它默认就是 `Self`（即当前类型本身）。

- `Rhs` 只是一个名字（Right Hand Side 的缩写，意为“右操作数”）。你可以把它改成 `T`、`Other` 或任何你喜欢的名字。
- `=` 后面的部分就是默认值。
- `Self` 是 Rust 中的一个关键字，代表当前正在实现该 `trait` 的类型本身,你也可以使用`i32`、`f64` 等具体类型。

### 使用默认泛型类型参数

```rust{2,10}
// 定义一个带默认泛型类型参数的 Trait
trait Add<Rhs=Self> {
    type Output;
    fn add(self, rhs: Rhs) -> Self::Output;
}

struct MyNumber(i32);

// 实现 Trait，使用默认的 Rhs（即 Self,此处是 MyNumber）
impl Add for MyNumber {
    type Output = MyNumber;

    fn add(self, rhs: MyNumber) -> MyNumber {
        MyNumber(self.0 + rhs.0)
    }
}

fn main() {
    let a = MyNumber(5);
    let b = MyNumber(10);
    let result = a.add(b); // 这里没有指定 Rhs，默认就是 MyNumber
    println!("{}", result.0); // 输出 15
}
```

### 使用自定义泛型类型参数

```rust{2,10}
// 定义一个带默认泛型类型参数的 Trait
trait Add<Rhs=Self> {
    type Output;
    fn add(self, rhs: Rhs) -> Self::Output;
}

struct MyNumber(i32);

// 实现 Trait，指定 Rhs 为 i32
impl Add<i32> for MyNumber {
    type Output = MyNumber;

    fn add(self, rhs: i32) -> MyNumber {
        MyNumber(self.0 + rhs)
    }
}

fn main() {
    let a = MyNumber(5);
    let result = a.add(10); // 我们实现了 Add<i32>，所以会使用那个实现
    println!("{}", result.0); // 输出 15
}
```
