# 思想内核

## 内核核心

- 三种态度: 静,勤,恒;明,恶,利
- 三个维度: 思想,语言,行为
- 拳头长在脑子里,要学会动脑而不是靠蛮力;富在术数，不在劳身！利在局势，不在力耕！
- 人既无虎狼之爪牙，亦无狮象之力量，却能擒狼伏虎训狮猎象，何也？唯智慧尔

## 目标的建立

- 实现自我价值，成为资本家
- 成为卓越的领导者，决胜千里之外
- 技术型战略领导者: 技术让你拥有判断未来的能力，领导力让你让未来发生。

## 实现的手段

- 不断地积累原始资本
- 一定要学会营销和洗脑，这是成功的产品背后的力量
- 在中国营销大于产品,这是一个酒香也怕巷子深的时代,就像代币,其实本质都一样,可为什么有的能上亿的市值?
- 洗脑是一个非常好的手段，获得足够的话语权，有越多的信众就能做越多的事，洗脑要口才好，逻辑缜密

## 警惕注意

- 信息茧房（垃圾充斥），尤其是在大数据分析喜好的今天，所有推送的信息都是筛选过的你喜欢的，每天都被这些信息垃圾包围。涉猎更多知识，了解更多领域，不断地学习，拒绝单一信息来源。
